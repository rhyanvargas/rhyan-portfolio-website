# Classifying a row

Read when a migration row, tag, or user request could be either a technology or a skill.

- **Technology** — you can install, import, host, or vendor it. One product or language.
- **Skill** — a method you can apply with many tools. No single install.

| Put in technologies | Put in skills |
|---------------------|---------------|
| `GraphQL`, `PostgreSQL`, `Docker`, `GitHub Actions`, `Figma`, `Next.js` | `REST API Design`, `CI/CD`, `Accessibility`, `State Management` |
| The word `GraphQL` alone | `GraphQL schema design` (the method, not the tool) |

Role labels (`Frontend Development`, `Backend`) are neither a technology `category` nor a skill `domain`. Do not copy a tool string list into the skills collection.

If a legacy label is both (for example "Docker and container design"), split it into the tool plus the capability. Do not drop either half.
